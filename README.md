# ⚡ TaskPulse — Git Practice Kanban Board

A lightweight, modern Kanban application built to master Git workflows:
- Feature Branching (`feature/*`)
- Commits & Atomic History
- Remote Pushing & GitHub Pull Requests (PRs)
- Fast-Forward vs 3-Way Merges
- Merge Conflict Resolution
